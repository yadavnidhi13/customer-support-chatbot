# 💬 Customer Support Chatbot

A web-based customer support chatbot designed to help users find answers to frequently asked questions and access basic customer support features.

## ✨ Features

- 💬 Interactive chatbot interface
- ❓ FAQ-based responses
- 🛠️ Admin panel
- 📦 Demo order data
- 📝 Feedback functionality
- 📁 File upload support
- 🌐 Web-based user interface

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Multer

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm on your computer.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/yadavnidhi13/customer-support-chatbot.git
   ```

2. Open the project directory:

   ```bash
   cd customer-support-chatbot
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   npm start
   ```

5. Open your browser at the local address configured by your server, typically `http://localhost:3000`.

*Check `server.js` and `package.json` for the correct port and available scripts.*

## 🔐 Security Notes

- Do not commit API keys, passwords, or other secrets.
- Keep environment variables in a local `.env` file and exclude that file from Git.
- Use demo data only in the public repository.
- Protect admin routes and validate uploaded files before using this project in a real application.
